Setup Tabel Database Supabase

Copy & Run SQL ini sekali saja di SQL Editor Supabase kamu agar sinkronisasi Cloud aktif.

create table if not exists public.basketball_sessions ( id uuid default gen_random_uuid() primary key, user_id uuid references auth.users(id) on delete cascade not null, user_email text, drill_name text not null, zone_id text not null, shots_made int not null default 0, shots_attempted int not null default 0, shot_events jsonb default '[]'::jsonb, duration_seconds int default 0, notes text, created_at timestamptz default now() ); alter table public.basketball_sessions enable row level security; create policy "Users can manage own basketball sessions" on public.basketball_sessions for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
*Jika belum dijalankan, data tetap tersimpan aman secara otomatis di LocalStorage perangkat.
